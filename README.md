# ping-pong-pygame
A simple ping-pong game made using Pygame.
# Features
- Two game modes:
  - Vs Computer
  - Vs Friend
- Player controls:
  - W / S — Move the left paddle
  - UP ARROW / DOWN ARROW  — Move the right paddle
  - SPACE — Start the game
# How to Play
Choose a game mode and press SPACE to start.
